//		FC PICOプログラム更新方法
//
//==================================================

①FC PICOのシェルをあけて基板を取り出す

	https://x.com/HD64180/status/2002561004165865570

②基板上のマイコン ラズベリーパイ PICO2にUSB Type-Cケーブルを接続



③プログラムを書き込む
	書き込みたいプログラムの下記バッチファイルを実行する

	sample_game\upload.bat
	
	tuto1_hw\upload.bat

	tuto3_3d\upload.bat


[補足]
	sample_game はゲームメインをアセンブラソースで作る方式の最終バージョンです。V1.06F

	tuto1_hw はシンプルなハローワールド表示サンプルです。FC PICOで自作プログラムを作る際の雛形にどうぞ
	
	tuto3_3d はsample_gameをベースにゲームメインをC言語に作り直し、表示系を完全3D制御に作りななおし
	ゲーム内容も見直したものです。ゲームレジェンド42（2026年9月20日)に配布したバージョンです V1.07


	正常に更新出来ない場合は後述のBOOTモードでマイコンを起動してからupload.batを実行して下さい。


④「③」でプログラム転送終了後、ファミコンに基板を差しこんで電源ON

	うまく起動しない場合はファミコンのリセットボタンを押す、電源を入れなおす
	基板を差し込み直すなどを試してみて下さい。



[基板上のマイコン ラズベリーパイ PICO2をBOOTモードで起動する]

	マイコンボード上にある BOOTボタンを押しながらUSB Type-Cケーブルを
	パソコンに接続する。（RESETボタンが付いているマイコンボードの場合は
	USBケーブルをパソコンと接続後にBOOTボタンを押しながらRESETでもOK）
	
	BOOTモードで起動するとパソコン上にドライブが追加されます。

	https://x.com/HD64180/status/2002571221913993560
